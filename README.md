# College-course-registration-system-
A system for managing college course registration, including course selection , student enrollment and registration management
Problem: Fee payment, verification, subject listing and registration are disconnected, manual and often delayed.
Solution: One unified flow from fee verification to course registration, clear for both students and staff.
Features: Fee verification, faculty/HOD-fixed subject list, backlog course registration, register/drop courses.
Documentation: Use case diagram and class diagram are included in the report.
